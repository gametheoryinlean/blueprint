Zero-Sum Game

A two-player strategic game is zero-sum if, at every strategy profile $\sigma$, the two players' payoffs add to zero:

$$u_0(\sigma) + u_1(\sigma) = 0.$$

A constant-sum game fixes the same sum to a constant $c$ instead of zero. In a zero-sum game, player 1's payoff is the negative of player 0's payoff, so the game can be studied through a single payoff function.
