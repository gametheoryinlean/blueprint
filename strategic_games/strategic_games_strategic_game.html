Strategic Game

A strategic game (or normal-form game) is a tuple $(I, (S_i){i \in I}, (u_i){i \in I})$ where $I$ is a set of players, $S_i$ is the strategy set of player $i$, and $u_i \colon \prod_{j \in I} S_j \to U$ is the payoff function of player $i$.

In the Lean formalization, this is a structure with fields strategy : ι → Type* and payoff : Profile → ι → U, where Profile = ∀ i, strategy i.
