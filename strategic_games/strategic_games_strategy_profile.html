Strategy Profile

Given a strategic game $(I, (S_i), (u_i))$, a strategy profile is a tuple $\sigma = (\sigma_i)_{i \in I}$ where $\sigma_i \in S_i$ for each player $i$.

In Lean, a profile is ∀ i, G.strategy i.
